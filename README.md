The goal of the Final Project is to develop and design your own database on anything of interest. In my case, I was inspired by my personal need of organizing and identifying my thousands and thousands of travel photos.

The Final Project includes three mandatory files:
- `DESIGN.md`: describes the database's purpose, scope, entities, relationships, optimizations, and limitations
- `schema.sql`: an annotated set of `CREATE TABLE`, `CREATE INDEX`, `CREATE VIEW`, etc. statements that compose the database’s schema
- `queries.sql`: an annotated set of `SELECT`, `INSERT`, `UPDATE`, `DELETE`, etc. statements that users will commonly run on the database

To experiment and ensure my database made sense and functioned properly, I created mock data in the form of CSV files and imported them to the `project.db` file.
